One firmware for every helmet: the display is now set up by a `display.json` file on the SD card, with support for HUB75 panels, MAX7219 8×8 matrices and custom NeoPixel boards.

## ProtoFace V7.0

**Download:** `ProtoFace-V7.0.uf2`. There are no more separate Mk2 / Mk3 files: the same
firmware runs every helmet, and the display it drives comes from `display.json`.

### Setting up (do this when updating from V6.x)
1. Get a `display.json` for your helmet:
   - **Mk2** (6 + 5 panels): `mk2.json` from the files below
   - **Mk3** (7 + 7 panels): `mk3.json` from the files below
   - **Anything else**: build one with the **Display Builder** on the website, or start from
     `hub75-1x64x32.json`, `hub75-2x64x32.json`, `max7219-single-side.json` or
     `neopixel-custom-eye.json`
2. Name it **`display.json`** and copy it to the **root** of the SD card, next to your `.anim` files.
3. Flash `ProtoFace-V7.0.uf2` (online flasher, or hold BOOTSEL, plug in and drag the file onto
   the drive), put the card in and power on.

At boot the firmware checks `display.json` and copies it into the Pico's flash, so the
helmet keeps working without the card. To change the display, replace the file on the card
and reboot (or send `reload`). A bad file is rejected and the old setup is kept; `status`
and `display` over Bluetooth say why.

### New
- **Any display.** WS2812 / NeoPixel panels in any arrangement, HUB75 RGB panels (via
  Adafruit Protomatter) and MAX7219 8×8 matrices, with the LED pins set in `display.json`.
  The SD card, microphone, USB-PD and wireless pins are fixed and can't be taken by a config.
- `display` shows the loaded display config; `ident` shows every panel's position on its chain.
- The **"NO SD"** fallback face is drawn for whatever display is set up.
- `display.schema.json` and [docs/display-config.md](https://github.com/RiotTheClanker/ProtoFace/blob/master/docs/display-config.md)
  describe every field.

### Animations
- Your existing Mk2 / Mk3 `.anim` files keep working with `mk2.json` / `mk3.json`.
- For other displays, make `.anim` files with the website's Animation Maker or
  AnimFile Maker **V5**, using the same `display.json`.

### Changes from V6.2
- The `map left` / `map right` panel-order commands are replaced by the `chain`, `flip`
  and `rotate` settings in `display.json`.
- A Pico that has never had a `display.json` lights nothing until it gets one.

### Known issues
- **HUB75 hasn't been tested on real panels yet.** It builds and the configs are checked, but
  if you try it, please report how it looks.
- With no display config in flash and no SD card, the Pico stays dark instead of showing
  "NO SD" (it doesn't know what display to draw on).
- On mirrored layouts the centre panels can stay unlit on the fallback face, and on a mirrored
  two-panel HUB75 setup the "NO SD" text reads backwards on one side.
