## ProtoFace V6.1

One firmware for both helmets. Pick the file for your board:

| Board | File |
|---|---|
| **Mk2** (layout 11: 6 + 5 panels, 704 LEDs) | `ProtoFace-Mk2-V6.1.uf2` |
| **Mk3** (layout 14: 7 + 7 panels, 896 LEDs) | `ProtoFace-Mk3-V6.1.uf2` |

**Flash:** hold **BOOTSEL** on the Pico 2 W while plugging in USB, then copy the `.uf2` onto the `RPI-RP2` drive, or use the flasher on the website.

### Fixes
- **Mk3 right side was dark on the fallback frame.** The built-in frame had nothing on the right-hand panels. They now show a mirror image of the left side.
- **Bluetooth commands are more reliable.** Commands no longer run at the same time as SD card reads. Long replies (like `list`) are sent in pieces instead of being cut off.
- **Sound-triggered frames advance.** They advance when the mic level rises past 128 (after at least the frame's duration), instead of never advancing.
- **More robust SD playback.** Frames are read in one go and seeking is faster. `next`/`prev` on an empty file no longer crash, a failed first frame is detected, and `START.ANIM` in capitals is recognised.
- **Clear build error for a mismatched fallback frame.** A frame exported for the wrong layout now stops the build with a message instead of silently changing the layout.

### New
- `bright <n>` sets brightness from 0 to 255. USB-C power limiting still applies on top.
- `fallback` switches to the built-in frame.
- `status` shows the firmware version, board, brightness, power and mic level.

### Kept from V6 and the Mk2/Mk3 branches
- The left-strip panel-order fix for the reversed wiring.
- USB-C PD (HUSB238) power budgeting with per-frame dimming, and the `power` command.
- SPW2430 mic scaling (noise floor, loudness curve, attack/decay).

### Notes
- The `.anim` file format is unchanged, so existing animations still play.
- Mk2 and Mk3 are now built from the same `master` branch. The `Mk2-Protogen` and `Mk3-Protogen` branches are kept but are no longer updated.
